# 可选 Muon 实施计划

[实验设计](../specs/2026-11-25-muon-lora.md)

1. 在正式训练入口添加优化器选择，沿用同一实验配置，记录实际采用的参数。以启动命令回归测试检查 AdamW 默认值、Muon 参数以及 Hydra 的最终映射。
2. 为固定版本的 veRL 添加可选补丁。初始化 Muon 时选择原始二维 LoRA 参数，检查首步动量及恢复行为。验收已装旧补丁和全新 checkout 两种情况。
3. 在正式 PyTorch 环境用 CPU 上的小型 FSDP 网络执行更新、保存、恢复及下一步对比。检查基座冻结、FP32 状态和完全一致的续训结果。训练质量留给独立 Tau2 实验评估。
